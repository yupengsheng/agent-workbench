# 领域模型草案

| 实体                   | 职责与关键字段                                                   |
| ---------------------- | ---------------------------------------------------------------- |
| User / Role            | 身份、启停状态与权限集合                                         |
| Workspace / Membership | 业务空间与成员归属；不是一个可任意提交的宿主机路径               |
| ExecutionEnvironment   | 服务端/LOCAL、Runner 身份、资源根、网络与沙箱配置                |
| Agent / AgentVersion   | 可编辑配置与不可变发布版本；角色、工具、Skill、模型约束、限制    |
| ModelConnection        | 服务端连接、密钥引用、模型标识、能力与允许的使用范围             |
| Session                | 用户的长期交流上下文、workspaceId、ownerId                       |
| Run                    | 一次执行，sessionId、parentRunId、触发者、状态、快照、预算、租约 |
| Step / ToolInvocation  | 模型轮次与工具调用；参数摘要、执行状态、结果引用、幂等键         |
| Approval               | 操作摘要、审批人范围、状态、截止时间与决策                       |
| Artifact               | 文件/报告/大输出的存储引用、摘要、大小、类型、所属 Run           |
| RunEvent               | runId、单调 sequence、类型、时间、关联对象与内容                 |
| AuditRecord            | 身份、动作、资源、策略结果、调用和配置版本引用                   |

## 三个关键区分

**AgentVersion 是配置，Run 是执行。** 每次 Run 固化完整 Agent 配置、模型选择及参数、工具版本、策略版本、工作区绑定和输入引用。管理员修改配置影响新 Run；运行中的任务不静默切换规则，权限撤销应及时生效。

**Session 是交流容器，Run 是生命周期。** 追问可创建新 Run 并引用之前产物；一次 Session 可有多个 Run。MVP 同一 Session 串行运行，子任务有独立 Run 和上下文，通过 parentRunId 关联。

**Workspace 是授权范围，执行目录是资源。** 目录由服务端配置或已注册 Runner 提供，不能仅凭请求中的路径赋予访问权。所有任务、产物、事件查询都检查 Workspace 成员与对象权限。

## 版本与追溯

历史版本保留；回滚通过基于旧配置发布新版本实现。外部模型服务未提供固定模型快照时记录服务端返回的标识与时间，不宣称可以完全复现。执行轨迹可回放；重新执行属于新的 Run，可能因模型和外部环境变化产生不同结果。
