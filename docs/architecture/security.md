# 安全、权限与执行边界

状态：身份、Workspace membership、模型配置隔离、结构化审计、受控文件/Shell 和网页获取边界已实现；生产级资源隔离与身份集成仍按路线建设。

## 有效权限

有效能力 = 用户授权 ∩ 工作空间策略 ∩ Agent 版本权限 ∩ Run 授权 ∩ Runner 能力。子任务再与父任务权限取交集，不能提权。策略判断必须位于执行边界，UI 隐藏按钮与模型提示均不能替代服务端授权。

权限档位可以作为易用预设：只读、工作区读写、受控执行。预设展开为明确规则。每条规则指定工具、资源、操作和 allow/deny/approval；deny 优先。审批是一种针对具体动作的受控授权，不能绕过平台硬拒绝。

## 审批

审批绑定 invocationId、工具及版本、规范化参数摘要、工作空间、资源范围、策略版本和截止时间。批准时重新校验权限；参数、目录或策略变化后重新判断。记录批准者与实际触发者，过期/重复批准不能再次执行。

模型风险分类只能辅助解释。未知分类输出、解析错误和无法验证的授权不能默认放行。主界面聚合整棵任务树的审批，审批状态持久化，Runner 重启后不能遗失或默认批准。

## 沙箱与网络

服务端命令使用每个 Run 或隔离工作区的非特权执行环境，限制 CPU、内存、磁盘、进程数与时长。当前模型只能通过 `propose_shell_command` 生成待审命令；批准后 Runner 使用 bubblewrap 创建 UID/GID 65532、独立 PID/网络命名空间、固定环境变量和工作区挂载。缺少 bubblewrap 时拒绝执行，执行中失联记录结果不明且不重试。工作目录不等于安全沙箱；字符串前缀路径检查不足以处理符号链接和路径竞态。

默认禁止工具外网，按部署策略开放模型和工具目标。网页抓取要求部署开关、模型能力和非空域名白名单，校验全部 DNS 结果并把连接固定到已校验地址；每次重定向重新检查，拦截元数据服务等受保护地址。内部业务系统使用显式连接器授权。执行容器不持有平台密钥和数据库凭证。

## 数据与审计

密钥引用与配置分离，脱敏展示，避免日志和产物泄露。上传、下载、事件订阅都执行对象归属检查。审计记录可追加，不赋予普通应用管理操作修改/删除历史的能力；生产需要保留周期、备份与可选不可变存储，不能仅凭数据库表宣称防篡改。

文件、网页和工具输出是外部内容，不得改变系统授权和用户目标。日志展示公开行动摘要，不默认保存完整内部思维链。真正的离线部署必须同时使用内网模型、依赖源和关闭出网的工具策略。

## 必须覆盖的验证

跨工作空间读写/下载/订阅被拒；路径穿越和符号链接逃逸被拒；审批参数变更失效；子任务无法提升权限；取消后不再接受新调用；模型/工具输出无法覆盖权限；恢复不会无条件重复外部副作用。
