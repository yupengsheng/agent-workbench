## 横向 Definition of Done

- 需求可追溯到页面、组件、接口、事件和测试；业务成功与模型结束分开。
- 变更有明确失败路径；状态迁移用条件更新；幂等/并发/取消必须有行为测试。
- CI：格式、类型、构建、模块边界、关键行为测试通过；UI 主路径键盘可达，文本对比目标 WCAG AA。
- 稳定公开接口有版本策略；错误码与恢复说明同步；数据库不修改已发布迁移。
- 新依赖记录用途、许可证、维护状态、替代方案；没有未评估的关键漏洞，不用测试覆盖率单个数字代替风险评审。
- 文档标注实现/验证状态，部署变更有可执行升级与回退步骤。

## 性能与运行目标

M2 基准环境至少记录 CPU/内存、数据库版本、模型标识、并发与网络。目标：控制 API（排除模型/工具）P95 < 300ms；持久化事件到已连接浏览器 P95 < 1s；取消请求到取消信号传播 P95 < 2s，进程真正停止独立观测。10 个并发 Run 起测，不能把这些目标当成已测结果。

M5 单机试点初始目标 RPO ≤ 24h、RTO ≤ 4h；企业需求更严格时先调整备份/高可用设计再承诺。记录备份时刻、恢复时长与恢复后的审批/Run 一致性。
