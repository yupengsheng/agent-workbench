# MVP 实施路线

按依赖顺序逐项交付，不以未经评估的周数承诺工期。每项合并时更新验收状态。

- [x] 独立 Git 仓库与目录职责。
- [x] npm workspaces、共享契约、Web/API 骨架。
- [x] 产品、架构、安全和运行语义草案。
- [x] 开发命令、格式、类型检查和构建 CI 配置。
- [x] 完成初始化后的本地构建与连通性验证。

交付：新开发者可按根 README 启动 Web 与 API。M0 不提供模型调用与任务执行。

验证记录（2026-09-20）：格式、类型检查与生产构建通过；两个健康接口与未知路由 404 通过；实际启动 `npm run dev`，Web 首页、API 直连和 Vite 代理均返回预期结果，验证后停止服务。Docker 当前环境未安装，开发数据库 Compose 尚未运行验证。

- [x] 工作空间查询/创建、owner membership 与资源归属基础校验。
- [x] 提供只允许空用户库执行的管理员初始化命令。
- [x] 模型连接登记、Workspace 隔离、托管密钥加密存储、secretRef 引用和脱敏响应。
- [x] ModelPort、DeepSeek OpenAI-compatible 适配器和自研兼容模型扩展边界。
- [x] 模型连接 baseUrl、托管/环境密钥解析、管理员配置页面和触发测试接口。
- [ ] 配置真实 DeepSeek 密钥并完成模型能力测试。
- [x] Agent 草稿、配置版本、模型连接归属校验和单版本发布。
- [x] Workspace 创建、模型连接创建/修改的管理审计和只读查询。

## M2：单 Agent 只读闭环

入口范围：用户工作台 `/app` 先服务 Run 提交和过程查看；管理员控制台 `/admin` 与 Feishu 通道先完成只读配置/通知能力，写入和审批随 M3 进入。

- [x] C 端选择 workspace 模型并进行同步多轮对话。

- [x] Session、Run、Step、Artifact 数据模型；同步对话写入 Run/Step/Event，页面刷新可从 Session 恢复最近一轮。
- [x] 单模型 Runner 领取/心跳/租约与明确失败状态。
- [x] 单模型后台查询、取消确认、60 秒超时与单次 Token 输出上限。
- [x] 可注入模型、工具和持久化的 TAO 循环（单层、最多 8 轮）。
- [x] 文件读取/搜索工具，工作区真实路径检查（read_file、glob、grep；只读）。
- [x] TAO 循环的步数、工具调用数、运行时限及工具取消；累计 usage 已落库。
- [x] 多模型 Jev 路由：候选快照、服务端 Choice 判断、置信度阈值、审计事件和固定模型兼容路径。
- [x] Run/Step/Event 状态和事件持久化。
- [x] C 端展示 Run 过程事件、Jev 路由结果和实际使用模型。
- [x] Web SSE 实时过程、事件游标和断线回退轮询。
- [x] Mao 风格三栏工作台与持久化会话侧栏；会话按 workspace 和用户隔离，支持切换、刷新恢复和新建任务。
- [x] 代码目录分析报告及来源引用（`analyze_workspace` 只读工具，返回文件统计、入口候选和可回指路径）。

验证记录（2026-09-21）：测试 ECS 已应用 `0005_runs_sessions_artifacts.sql`；在同机独立临时 schema 中执行全部迁移和 Fastify 集成测试，4 组行为用例通过，覆盖成功/失败落库、鉴权、用户/工作空间隔离、缺失密钥不创建 Run、API 实例重建后读取与续聊。Playwright 浏览器回归通过，覆盖刷新恢复、恢复期间禁止发送、清空和工作空间切换。两类测试已接入 CI；模型使用模拟响应，真实 DeepSeek 成功对话仍待独立验证。这是本轮前的基线记录；M2 整体尚未验收。

TAO 增量（2026-09-22）：新增 `packages/runtime` 的单层工具循环和 `packages/tools` 的只读工作区工具；工具调用以独立 Tool Step 和事件持久化，最多 8 轮/16 次调用。单元测试覆盖路径隔离、符号链接拒绝、glob/grep、工具观察后续模型调用和轮次预算。真实模型工具调用、刷新期间实时事件和大结果 Artifact 尚未验收。

目录分析增量（2026-09-23）：新增 `analyze_workspace` 只读工具，使用现有工作区路径策略和遍历上限，返回文件数量、目录数量、扩展名分布、入口候选及 `sources.path` 引用。单元测试覆盖报告结构、来源排序和统计结果；模型是否在真实 DeepSeek 对话中稳定调用该工具仍需单独验收。

Runner 增量（2026-09-21）：独立进程接管用户模型调用，API 返回 202；9 组数据库行为测试及浏览器回归通过，新增竞争领取、同会话串行、运行中取消、过期租约拒绝旧结果、配置变更拒绝执行、超时和停止。新增 `0006_runner_leases.sql`，接口与架构取舍见 [ADR-0006](../decisions/0006-background-chat-runner.md)。验收使用模拟模型；SSE、TAO 和自动检查点恢复仍未实现。

验收：真实模型读取样例工作区并生成报告；刷新可恢复过程；预算耗尽和取消会停止后续调用。拒绝未授权文件范围。

## M3：受控动作

- [x] 单文件受控写入与可审阅变更：Runner 领取批准提案，重新校验前置 SHA 后原子替换；结果不明不自动重试。
- [x] 文件变更提案预览：`propose_file_change` 返回统一 diff、前后 SHA-256、来源路径和审批要求；当前不会写入磁盘。
- [ ] 生产级执行资源隔离：cgroup CPU/内存/进程计量和工作区磁盘配额。
- [x] Shell 工具、非特权断网沙箱、进程退出与取消语义。
- [x] 确定性策略和持久化审批：提案绑定 Run/Step、摘要、策略版本和 24 小时有效期；批准目前只记录审阅结果。
- [x] 受控 Shell 基础：双开关启用、bubblewrap 非特权/断网命名空间、固定环境、敏感路径遮蔽、超时/CPU/内存/进程数/输出限制和进程组取消。
- [x] 模型调用、Jev 路由和工具调用结构化审计；审计元数据不保存提示词、模型输出、工具参数、命令或密钥。
- [x] 文件与 Shell 副作用结果不明终态；未知结果不自动重试。
- [x] Shell 审批持久化、一次性执行领取和结果不明终态；未知结果不自动重试。
- [x] 可选网页获取：部署/模型双开关、域名白名单、固定 DNS 地址、逐次跳转检查和文本响应预算。

验收：拒绝审批时没有真实副作用；批准只作用于准确的调用；沙箱不能访问平台凭证；网页不能绕过网络策略。当前增量已覆盖前置 SHA、一次性应用领取、结果不明状态、结构化调用审计，以及受域名和地址限制的文本网页获取。审计表当前是应用级追加记录，生产保留、备份和不可变存储仍属于 M5 运维建设；cgroup 与工作区磁盘配额尚未完成。

## M4：多 Agent 与长任务

- [ ] 一层异步子 Run、结构化结果、只读子任务并行。
- [ ] 主/子任务过程视图和统一审批入口。
- [ ] 任务树预算、并发限制与取消传播。
- [ ] 上下文压缩与原文归档。
- [ ] 重启恢复、重复结果去重、外部副作用核对。

验收：主 Agent 委派两个独立分析任务并汇总报告；子任务不能提权；重连或重启不重复注入结果，不盲目重复执行写操作。
