# MVP 实施路线

按依赖顺序逐项交付，不以未经评估的周数承诺工期。每项合并时更新验收状态。

## M0：开发基线

- [x] 独立 Git 仓库与目录职责。
- [x] npm workspaces、共享契约、Web/API 骨架。
- [x] 产品、架构、安全和运行语义草案。
- [x] 开发命令、格式、类型检查和构建 CI 配置。
- [x] 完成初始化后的本地构建与连通性验证。

交付：新开发者可按根 README 启动 Web 与 API。M0 不提供模型调用与任务执行。

验证记录（2026-09-20）：格式、类型检查与生产构建通过；两个健康接口与未知路由 404 通过；实际启动 `npm run dev`，Web 首页、API 直连和 Vite 代理均返回预期结果，验证后停止服务。Docker 当前环境未安装，开发数据库 Compose 尚未运行验证。

## M1：身份与配置基础

当前进度：已落地 PostgreSQL 连接边界、首个身份/工作空间/模型连接/Agent 版本/审计迁移和数据库就绪检查；账号、会话、权限服务、模型密钥适配和配置 API 尚未完成。

- [ ] 接入 PostgreSQL，建立迁移和开发种子数据。
- [ ] 本地账号、密码哈希、会话管理；无硬编码默认生产密码。
- [ ] 工作空间、成员、角色与资源归属校验。
- [ ] 模型连接和服务端密钥存储；模型能力测试。
- [ ] Agent 草稿与完整配置版本发布。
- [ ] 管理变更审计。

验收：管理员创建工作空间、账号、模型和 Agent；另一工作空间用户无法读取这些受限资源，浏览器与日志不出现真实密钥。

## M2：单 Agent 只读闭环

- [ ] Session、Run、Step、Artifact 数据模型。
- [ ] Runner 领取/心跳/租约与明确失败状态。
- [ ] 可注入模型、工具和持久化的 TAO 循环。
- [ ] 文件读取/搜索工具，工作区真实路径检查。
- [ ] 步数、Token、时长上限；取消；无输出/异常处理。
- [ ] 事件持久化、Web 实时过程和断线补齐。
- [ ] 代码目录分析报告及来源引用。

验收：真实模型读取样例工作区并生成报告；刷新可恢复过程；预算耗尽和取消会停止后续调用。拒绝未授权文件范围。

## M3：受控动作

- [ ] 文件写入与可审阅变更。
- [ ] 非特权执行沙箱与资源限制。
- [ ] Shell 工具、进程退出与取消语义。
- [ ] 确定性策略和持久化审批。
- [ ] 工具与模型调用审计、结果不明状态。
- [ ] 可选网页获取：网络白名单、DNS/跳转限制。

验收：拒绝审批时没有真实副作用；批准只作用于准确的调用；沙箱不能访问平台凭证；网页不能绕过网络策略。

## M4：多 Agent 与长任务

- [ ] 一层异步子 Run、结构化结果、只读子任务并行。
- [ ] 主/子任务过程视图和统一审批入口。
- [ ] 任务树预算、并发限制与取消传播。
- [ ] 上下文压缩与原文归档。
- [ ] 重启恢复、重复结果去重、外部副作用核对。

验收：主 Agent 委派两个独立分析任务并汇总报告；子任务不能提权；重连或重启不重复注入结果，不盲目重复执行写操作。

## M5：可交付的私有化 MVP

- [ ] 应用/Runner 镜像与完整 Compose，首次部署初始化向导。
- [ ] 反向代理 TLS、密钥配置、备份恢复演练与升级迁移。
- [ ] 内网模型与关闭外网条件下的验收。
- [ ] 固定样例任务集与质量/延迟/Token 基线。
- [ ] 安装、故障定位、数据保留和用户使用手册。

验收：在新环境按文档完成部署、样例任务、备份恢复与升级。当前 `infra/compose` 只有开发数据库，不代表 M5 已完成。
