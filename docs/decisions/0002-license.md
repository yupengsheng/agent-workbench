# ADR-0002：Apache-2.0 开源协议

日期：2026-09-20。状态：采用。依据：用户授权设置开源协议；目标为企业私有化部署、可扩展与长期维护。替代 ADR-0001 中“许可证待定”。

| 方案       | 商用/闭源衍生      | 专利条款                 | 修改版回馈要求                           | 本项目判断                                     |
| ---------- | ------------------ | ------------------------ | ---------------------------------------- | ---------------------------------------------- |
| MIT        | 允许               | 无 Apache 式明示专利授权 | 保留版权与许可声明                       | 简单，但对企业专利授权不如 Apache 清晰         |
| Apache-2.0 | 允许               | 明示专利授权与终止条款   | 保留许可/适用通知，修改文件说明变更等    | **采用**：便于企业集成与社区贡献               |
| MPL-2.0    | 允许组合为更大作品 | 明示条款                 | 修改的受覆盖文件按协议开放               | 文件级互惠适合库，增加集成边界解释成本         |
| AGPL-3.0   | 允许商用           | 有相关条款               | 修改版网络交互等情形涉及相应源码提供义务 | 适合强调网络服务改动回馈的产品，当前不作为默认 |

许可证不是竞争壁垒。Apache-2.0 允许他人商业使用、托管和在满足义务下制作闭源衍生版；项目优势需要依靠交付质量、治理、生态与服务形成。若商业目标要求限制竞争性托管，应重新评估策略，不能把此类限制擅自加进 Apache 原文并仍称 Apache-2.0。

## 落地

- 根 LICENSE 使用 Apache 官方完整文本；NOTICE 记录本项目版权归属。
- package.json 写入 SPDX 标识 `Apache-2.0`；`private: true` 仅表示不发布 npm，与许可证不冲突。
- 原型、Figma 插件、原创文档使用同一许可，外部库/字体/图标仍按其各自许可。
- 保留第三方许可证与来源；Mao 管理端布局和交互的衍生实现保留 MIT 版权与许可声明，见 `THIRD_PARTY_NOTICES.md`。
- GitHub 仓库可见性单独管理；设置开源协议不自动把已有私有仓库改为公开。

后续版本变更许可不能撤销已授予的 Apache 权利；接收外部贡献后重新许可还涉及贡献者权利。CONTRIBUTING 明确贡献按本项目许可提供，并采用 DCO 签署流程。
