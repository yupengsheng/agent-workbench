# ADR-0009：只读目录分析报告

状态：已接受并实现（2026-09-23）

## 背景

M2 要求用户可以让 Agent 分析授权工作区，并在报告中引用依据。仅依赖模型多次组合 `glob`、`grep` 和 `read_file` 会增加轮次和遗漏入口文件的概率，也无法稳定地产生统一的目录统计。

## 决策

在 `packages/tools` 增加只读 `analyze_workspace` 工具。它复用同一工作区路径解析、符号链接拒绝、隐藏目录/依赖目录过滤和遍历上限，返回：

- 文件与目录数量、总字节数和扩展名分布；
- 文件路径清单（不读取正文）；
- `package.json`、README、构建配置、应用入口和部署文件等来源候选；
- `sources.path` 引用约定，要求分析结论可以回指工作区内路径。

报告受文件数、来源数和工具输出大小上限约束，超限时结构化标记 `truncated`。工具没有写权限、命令执行权限或网络能力，不扩大现有 Runner 授权边界。

## 取舍

使用确定性报告工具可以减少模型探索轮次并让引用格式稳定，但它不会替代模型对文件正文的语义分析，也不会宣称依赖关系、运行时调用图或架构结论已经被静态证明。后续如果需要更丰富的图分析，应另建版本化分析器并把大结果存为 Artifact。
