# 信息架构

状态：规划。当前 Web 仍是开发首页和连接检查；用户工作台、管理员控制台和第三方通道按[入口与通道边界](../architecture/experience-surfaces.md)分阶段接入。

## 入口分层

| 入口                  | 首屏                               | 主要导航                                   |
| --------------------- | ---------------------------------- | ------------------------------------------ |
| 用户工作台 `/app`     | 最近任务、工作空间和 Agent         | 任务、Agent、审批、产物                    |
| 管理员控制台 `/admin` | 系统状态、模型连接和待处理治理事项 | 用户与成员、模型、Agent 版本、策略、审计   |
| 飞书等通道            | 会话/群聊中的任务卡片              | 提交只读任务、查看状态、接收结果和审批提醒 |

## 页面规划

| 区域       | 主要页面                              | 核心交互                           |
| ---------- | ------------------------------------- | ---------------------------------- |
| 工作台     | 最近任务、Agent 目录、工作空间选择    | 提交目标、选择工作区               |
| 任务控制台 | 主任务、子任务、执行时间线、文件/产物 | 查看过程、补充输入、取消、下载     |
| 待办       | 待审批操作                            | 预览准确参数/影响范围、批准、拒绝  |
| Agent 管理 | 配置、测试、版本                      | 创建草稿、发布、基于历史版本再发布 |
| 模型管理   | 连接、能力、可用范围                  | 服务端保存密钥、连接验证           |
| 治理       | 用户、工作空间、角色、策略            | 授权、回收访问、设置预算           |
| 审计       | 管理变更、Run 轨迹、调用明细          | 筛选、下钻、按权限导出             |

## 运行控制台

左侧展示任务列表；中间展示目标、运行摘要和工具时间线；右侧展示当前 Run 的计划、状态、预算与产物。子任务从任务树进入独立过程视图，避免将所有输出混进主对话。

主/子任务使用相同事件格式。审批入口汇总整棵任务树中的待审批操作，不能依赖用户当前打开的 Tab 才可见。用户关闭页面后，服务端执行继续；重新进入通过快照与事件游标补齐。

界面展示操作目的、工具输入输出、来源、错误与结果，不要求展示完整内部推理。任何“成功”状态需区分执行完成和业务验收通过。

## 状态与空态

没有模型时引导管理员配置连接；没有 Agent 时引导创建并发布；没有工作区时引导绑定资源。未实现模块标为待开发，不提供无效果按钮。失去连接显示可重试状态，审批超时、操作被拒、预算耗尽都有明确解释。
