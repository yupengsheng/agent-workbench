# 工具与策略（规划目录）

此目录尚无工具实现。后续提供标准工具描述、参数校验、策略判定接口与执行适配器，供 Runner 调用。

每个工具声明名称、版本、输入/输出 Schema、副作用类别、超时与重试语义。首批工具为文件读取/搜索/写入、沙箱 Shell、受控网页访问。

建议子目录：`registry`、`policy`、`filesystem`、`shell`、`web`。审批绑定工具名、已校验参数摘要、工作区与策略版本；参数变化必须重新决策。模型对危险性的判断只能补充提示，不能覆盖确定性策略。

工具结果需区分 success、error、denied、cancelled、outcome_unknown。大输出保存为产物并返回引用；来自文件/网页的内容不能覆盖系统权限规则。
